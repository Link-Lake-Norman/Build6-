# Future Ready™ Roles & Permissions

## Platform Administrator

Responsibilities:

- Manage platform configuration
- Manage organizations
- Manage users
- Review security activity
- Access audit reporting


## Organization Administrator

Responsibilities:

- Manage organization users
- Configure organization settings
- View organization reporting


## School / Program Partner

Permissions:

- View assigned students
- Manage programs
- Track outcomes
- Access approved reports


## Employer Partner

Permissions:

- Create opportunities
- Manage internships
- Review approved matches
- Track engagement


## Student

Permissions:

- Manage profile
- Build portfolio
- Track readiness
- Explore opportunities


## Governance Principles

Future Ready™ follows:

- Role-based access control
- Least privilege access
- Auditability
- Clear ownership of data
