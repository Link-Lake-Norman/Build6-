# Future Ready™ Admin Asset Vault

Private master archive for Future Ready™ curriculum, optional modules,
recovered builds, protected assets, and future add-ons.

Nothing stored here is automatically active in a cohort or curriculum.

Protected Ambassador curriculum and classroom assets.

- standalone student experience

## Experiences

- experience activities

- experience slides
- Day Two experience build

## Playbooks
Reserved for facilitator and program playbooks.

## Activities
Reserved for reusable activity builds and AI-generated classroom tools.

## Assessments
Reserved for assessment systems, rubrics, and evaluation tools.

## Recovered Builds
Reserved for older Future Ready™ components that should be preserved
without automatically returning to the live curriculum.

STATUS MODEL:
ACTIVE = currently used
AVAILABLE = ready for optional use
ADD-ON = optional curriculum extension
ARCHIVED = retained for preservation
RECOVERED = restored from a previous build
